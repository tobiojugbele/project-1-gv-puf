# Actuarial Credibility Assumptions Registry

* **Model Formulation:** Multiplicative partial credibility framework modeled as $Z = \frac{n}{n + k}$.
* **Parameter Assumption:** The credibility constant is fixed at $k = 50$.
* **Rationale:** Low-volume counties with few facility rows introduce random statistical noise. Setting $k=50$ safely shrinks low-sample county data variance toward the robust national baseline mean until the regional sample footprint stabilizes.
